What it does

Core features implemented across the stack

⚡ Real-time everything

Socket.io powers live chat, typing indicators, and instant notifications — no refresh needed.

🖼️ Media uploads

Images and short videos upload directly to Cloudinary with type/size validation.

🔐 Secure by default

JWT auth, bcrypt hashing, rate limiting, brute-force lockout, and input sanitization.

✅ Fully tested

Jest/Supertest on the API, Vitest/RTL on the UI, all wired into CI.

🚀 Performance-minded

Route-level code splitting, vendor chunking, gzip compression, cached static assets.

🐳 CI/CD & Docker

GitHub Actions lints, tests, and builds both apps; Docker Compose runs the whole stack locally.
